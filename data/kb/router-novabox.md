# NovaBox Router

## LED indicators
- Power — white: on; off: no power.
- Fibre — green: connected; red: no fibre signal; blinking green: connecting.
- Internet — green: online; orange: connected to fibre but no internet (authentication problem).
- Wi-Fi — blue: Wi-Fi on; off: Wi-Fi disabled.

## Changing the Wi-Fi name and password
Open http://192.168.1.1 in a browser while connected to the router, log in with the admin password printed on the router label, then go to Wi-Fi > Settings.
The Wi-Fi settings can also be changed in the NovaTel app under Home > NovaBox.

## Factory reset
Press and hold the reset button on the back for 10 seconds with a paperclip.
A factory reset restores the Wi-Fi name and password printed on the label and deletes all custom settings.
Use a factory reset only if a restart did not help and the Internet LED stays orange.

## Replacing a faulty router
If the router is faulty, NovaTel replaces it free of charge. The replacement is sent by courier within 2 working days after a ticket is opened.
